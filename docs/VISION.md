# LearnAI Vision

## Mission

**Make personal education available to every human, from age 3 to old age, in every language, through safe AI teachers that adapt to each learner's goals and progress.**

LearnAI is evolving from a tutoring marketplace into a lifelong AI education system.

## Product Identity

- **Repository name:** LearnAI
- **Product brand:** YourTeacher by LearnAI
- **Tagline:** Your personal AI teacher from first words to PhD.

## Core Engines

```text
LearnAI
├── Learner Profile Engine
├── Curriculum Engine
├── Tutor Persona Engine
├── Assessment Engine
├── Safety & Guardian Engine
└── Agent-Matrix Integration Layer
```

## Life Stages Supported

1. Little Learner (ages 3–6)
2. Explorer (ages 7–11)
3. Builder (ages 12–15)
4. Scholar (ages 16–18)
5. University (ages 18–25)
6. Professional (adult upskilling)
7. Senior Learner (older adults)

## Learning Loop

Every learning session should follow a mastery loop:

```text
Question → Answer → Feedback → Misconception Detection → Re-teach → Check Again → Progress Update
```

Lesson delivery style should be concise and adaptive:

```text
Hook → Explain → Example → Practice → Feedback → Tiny Reward → Next Step
```

## Family-First MVP

The first milestone is LearnAI Family, focused on children ages 3–8 and parents:

- Parent account and child profile
- Safe age-based teacher personas
- Daily 5-minute micro-lesson
- Parent summary and progress stars
- Child-safe defaults and session limits

## Long-Term Goal

LearnAI becomes an open, safe AI school for life, where each learner has a personalized team of AI teachers and a transparent mastery record.
